## Durable: ceramic studio calibration standing rules

- Quote kiln calibration per session, never per-hour.
- Verify older kiln controllers with external reference probes.
- Deliver untouched controller logs plus a separate recommendations report.
- No automated recipe tuning; client signs off before changes.
- Weekly status email, never daily, never phone-first.

## Durable: capture standards

- Record baseline sensor readings before each ramp test.
- Use three controlled ramp holds for drift checks.
- Preserve raw controller exports alongside the summary report.
