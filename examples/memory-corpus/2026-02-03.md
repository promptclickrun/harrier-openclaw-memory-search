# Memory: 2026-02-03

## Equipment note: kiln temperature probe kit

Bought a dedicated probe kit with two reference thermocouples so we can compare
the kiln controller reading against independent sensors. Some older controllers
report stable temperatures while the chamber still has hot spots, so checking
multiple shelves during a hold matters.

## Workflow lesson learned

A test batch warped because the top-shelf temperature ran hotter than the
controller display suggested. New rule: never trust the controller reading by
itself on older kilns. Validate with external probes before recommending recipe
changes. The studio was gracious about it, but the drift was avoidable.

## Pricing follow-up

Revised the per-session quote upward for multi-zone or high-temperature firing
profiles. Single-zone low-fire checks stay at the base rate. Documented this so
future jobs reference the same tiering.
